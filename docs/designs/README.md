# 测评页面设计

## 量化打分设计存档

- 设计文件：`scoring-method-design.html`，可在浏览器中打开查看交互原型。
- 设计范围：GSB 与量化打分切换、自定义分值区间及每档判定规则、每组两个音频独立评分，以及「其他」开放文本维度。
- 实际功能已实现：维度配置、按维度对照的 A/B 独立评分、文本观察、断点续答、导出与单问卷量化统计。使用和部署说明见 `../QUANTITATIVE_SCORING.md`。
- 原型中的保存、提交和示例音频控件仅用于交互演示，不会写入业务数据库。
- 此 HTML 保留为原始设计参考，不是业务应用入口；正式功能在问卷详情的「测评维度」和公开答卷中使用。
