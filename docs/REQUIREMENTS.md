# 需求文档（Requirements）

> 音频盲测评估平台 —— 产品目标、角色、功能、数据模型与业务规则。

## 1. 产品目标

为语音/TTS 模型效果评估提供一套 **盲测对比** 工具：同一段文案由多个模型合成音频，评审人在不知晓模型身份的情况下逐对比较，系统据此统计各模型胜率与显著性，输出客观的优劣结论。

## 2. 角色

| 角色 | 说明 | 认证方式 |
| --- | --- | --- |
| 管理员（admin） | 创建问卷、上传音频、配置组别、生成配对、发布/复制问卷、查看统计 | 账号密码登录 |
| 答卷人（评审人） | 通过分享链接打分，无需注册 | 免登录（仅填姓名） |
| 登录用户（user） | 保留的登录答题流（次要场景） | JWT 登录 |

## 3. 核心功能

### 3.1 创建盲测问卷（管理员）
- 填写问卷名称、评测文案（evaluationCopywriting）、评分标准（scoringStandard）。
- 批量上传音频，每个音频指定 **模型名（modelName）** 和可选 **组别（groupLabel）**。
- 支持格式：audio/mpeg、audio/wav、audio/mp4。
- 系统据评分标准文本自动解析 **评分维度**（解析失败回退为「整体效果」）。

### 3.2 音频与组别管理（管理员）
- 向已有问卷新增/移除音频。
- 批量设置音频组别（同一 query/文案归为一组）。
- 新建问卷与追加上传（文件/文件夹）均默认以文件名去掉最后一个扩展名作为组别；不去除数字前导零或模型前后缀。未传组别的上传请求由后端补默认值，显式自定义或清空则保留用户意图。
- 历史音频支持「按文件名补齐空组别」：只处理当前问卷的空组别，保留已有组别并跳过参考音频；事务写入，不自动重建配对或清空答卷。若文件名包含不同模型前后缀，需人工确认是否应归同组。
- 音频管理表格支持勾选、全选/取消全选，通过「批量编辑组别」统一设置或清空所选音频组别；不影响未选音频及其未保存的修改，组别最多 255 个字符。
- 批量保存校验问卷权限与全部音频归属，不允许修改其他问卷、已移除音频或参考音频；写入使用事务，失败时整体回滚。
- 保存组别不清空答卷。修改组别后需核查情绪准确度、音色相似度的组别配置；表格存在未保存的组别修改时不可生成配对。
- 音色相似度、情绪准确度的维度配置弹窗采用固定尺寸（不超过视口），标题和保存按钮固定，内容与组别列表均提供可拖动滚动条。组别支持忽略大小写的关键词筛选（空格、逗号分隔多个关键词，匹配任一）、仅看已选、全选/取消全部筛选结果及清空已选；每页最多展示 100 组，批量选择作用于全部筛选结果，不局限当前页。
- 情绪类别批量选择自动跳过已分配给其他情绪的组别，不覆盖其他类别；清除筛选保留已选项。失效组别提示并支持移除；所有选择仅在点击弹窗「添加/更新」后保存。
- 手动「生成盲测配对」：**同组内不同模型两两配对**，同模型不比较，空组别不参与。
- 上传/增删/改组别均 **不自动配对**，需管理员显式触发生成。

### 3.3 盲测配对规则
- 分组：按 `groupLabel` 归组。
- 配对：组内不同 `modelName` 两两组合。
- 消除偏见：随机左右位置 + Fisher-Yates 打乱整体展示顺序。
- 重建配对会 **清空该问卷旧作答与旧配对**（旧答案已失去意义）。

### 3.4 发布与分享
- 问卷状态：`draft` / `published` / `offline`。
- 发布时自动生成唯一 `shareToken`，形成免登录链接 `/q/:shareToken`。
- 可设置有效期（validFrom / validUntil）。
- 创建后可在问卷详情的「测评背景」卡片预览并编辑背景；草稿、已发布、已下线均支持，仅问卷所属管理员可修改。背景不能为空，支持多行文字；取消不保存，保存失败保留输入以便重试。
- 修改背景后，答卷人下次打开或刷新问卷时看到新内容；不改变发布状态或分享链接，不修改音频、组别、配对、评分维度及已有答卷。

### 3.5 答题（答卷人，免登录）
- 打开分享链接，填写姓名开始作答。
- 按维度的打分方法作答：GSB 为 **左更好 / 一样 / 右更好**；量化打分为左/右音频独立评分，显示每个分值的判定规则；「其他」分别填写两个音频的文本观察。
- 提交后记录 visitorName 与 visitorIp。
- 有效期外或未发布的问卷无法作答。

### 3.5.1 量化打分与开放文本
- 普通、音色相似度、情绪准确度维度可逐个选择 GSB 或量化。量化可配置最低分、最高分、步长，每档必须有非空判定规则；允许同分、零分与最多两位小数，2～101 档。旧维度缺省仍为 GSB。
- 「其他」维度使用开放文本，每个音频最多 5000 字，可配置是否必填；默认选填，不计算分数，仅保存并导出供后续自然语言分析。
- 量化与文本支持断点续答；提交检查已分配题目的所有必填项，拒绝越界分值、重复答案、类型混用和跨组评分。保存与提交使用事务，已提交不可覆盖。
- 已发布或已有答卷时禁止修改评分维度；无答卷可下线后改，有答卷请复制后配置。复制保留所有量表和文本设置。
- 详细规则与 0012 数据库迁移说明见 `QUANTITATIVE_SCORING.md`。

### 3.5.2 固定子问卷与限额发放
- 管理员在「分组发放」中指定每张子问卷的组别数量与发放份数，自动计算子问卷数量。以已生成配对中的有效组别为单位，随机分成固定、不重叠的子问卷；同组全部模型配对保持在同一张内。400 组设置每张 50 组、20 份，自动生成 8 张、总限额 160 份；不能整除时最后一张单独容纳余数组别（例如 410 组生成 8 张 50 组及 1 张 10 组），每张均按指定份数发放。组数超过题库则生成 1 张；最多生成 100 张。
- 子问卷共用父问卷的背景、维度、有效期和分享链接，不产生独立发布链接。配置同时保存组别及配对 ID，不是每人重新随机抽 50 组。仅未发布且没有任何答卷时可以生成、重分或停用方案；已有答卷请复制问卷再配置。
- 领取时从未领满的子问卷中等概率随机选择一张，在数据库事务中锁定父问卷、检查名额并创建答卷，防止并发超发。进行中、已提交、已评分都占用名额，不自动释放未完成的领取。相同浏览器标识 + 姓名续答复用同一答卷；已提交不可重复领取。匿名模式不保证跨浏览器/不同姓名的自然人去重。
- 公开页领取前不返回子问卷题目；领取后只返回所分配的配对。读取、保存、提交校验访客标识与分配范围，拒绝跨子问卷、重复或不适用维度的答案；提交必须覆盖该子问卷的全部适用维度。进度保存和提交使用事务，已提交不允许覆盖。
- 管理端显示每张子问卷的组数、配对数、限额、进行中、已提交、剩余份数及可筛选的固定组别列表；答卷详情和 Excel 标明子问卷编号。
- 启用后替代原 sampleSize 随机抽样，锁定音频、组别和配对修改；停用恢复全部组发放。存量问卷默认不启用，已有随机抽样与历史答案不变。
- 部署前在目标环境注入 DATABASE_URL，执行 `node scripts/apply-0011-migration.mjs --apply`，随后 `--check`。仅新增 questionnaires.subQuestionnairePlan（可空 JSON）及 responses.subQuestionnaireIndex（可空 INT），不回填或删除历史数据；可重复执行。启动检查缺列会停止启动，避免再次出现线上缺字段问题。

### 3.6 统计分析（管理员）
- 单问卷量化评分按「维度 × 实际模型」单独汇总评分次数、均值与最高/最低分；文本显示非空观察数。不换算 GSB、不合并不同量表，不计算统一量化答卷总分。
- Excel 保留两侧独立分值、文本、原文件名、音频 ID、模型及组别/配对/维度 ID，附评分规则工作表；用于后续自然语言分析。跨问卷聚合仍仅统计 GSB。
- 答卷详情及 Excel 导出保留左右音频的完整原文件名（含扩展名、模型前后缀及数字前导零），不再简写成「音频X」；文件名缺失时明确标注，不推测原名。仅影响管理员查看与导出，答卷人仍使用左/右盲测标识，不改写文件、配对或历史答案。
- **问卷统计**：答卷数、平均/最高/最低分、完成率。
- **盲测聚合**：按「模型对比 × 评分维度」聚合所有判断，计算：
  - win / tie / loss 计数与占比；
  - **GSB 分数** = (aWins - bWins) / total，范围 [-1, 1]；
  - **Wilson 95% 置信区间**（决定性对比，剔除平局）；
  - **双侧二项检验 p 值**（原假设 p=0.5），`p < 0.05` 判显著；
  - 显著时给出 winner 模型。
- 模型对比按字典序规范化（modelA < modelB），消除左右差异。

### 3.7 复制问卷（管理员）
- 一键复制：问卷基本信息、音频记录（共享 OSS 对象）、评分维度，并按组别重建盲测配对。
- 副本为 draft 状态、shareToken 置空（避免唯一约束冲突）。

### 3.8 AI 辅助（保留能力）
- `generateQuestions`：据文案与评分标准自动生成单选/多选/主观题（次要场景）。
- 主观题 AI 评分 + 客观题自动判分 + 整体 AI 评语。

## 4. 数据模型（关键表）

| 表 | 用途 | 关键字段 |
| --- | --- | --- |
| `users` | 用户/管理员 | openId、role(user\|admin) |
| `questionnaires` | 问卷 | title、status、shareToken、evaluationCopywriting、scoringStandard、validFrom/Until |
| `audioFiles` | 音频 | fileKey、fileUrl、modelName、groupLabel、questionnaireId |
| `blindTestPairs` | 盲测配对 | leftAudioFileId、rightAudioFileId、pairIndex |
| `evaluationDimensions` | 评分维度 | dimensionName、weight、maxScore、scoringConfig |
| `responses` | 答卷 | visitorName、visitorIp、status |
| `answers` | 单条作答 | blindTestPairId、evaluationDimensionId、blindTestChoice、audioEvaluation |
| `questions` / `questionnaireStats` | AI 题目 / 缓存统计 | — |

## 5. 业务规则汇总

1. 仅 **同组、不同模型** 的音频才配对；同模型、空组别不参与。
2. 配对左右位置随机、展示顺序打乱，保证盲测公正性。
3. 音频/组别变更后必须重新「生成配对」，且会清空旧作答。
4. 答卷人免登录，问卷须为 `published` 且在有效期内方可作答。
5. 统计仅对非平局的「决定性对比」做显著性检验。
6. 复制问卷共享 OSS 对象（不重复上传），副本独立于原问卷。
7. DB 只存音频 key/url，实体文件在 OSS；生产容器走 OSS 内网 endpoint。

## 6. 非功能性需求

- **性能**：多音频上传并行化（Promise.all），OSS key 按日期时间戳归档避免同前缀堆积。
- **安全**：管理端接口 `adminProcedure` 门控；答卷链接仅暴露音频与维度，不泄露模型名。
- **可移植**：脱离 Manus 平台，用京东云 OSS + 账密登录独立部署（JDOS，端口 8080）。
- **可测试**：vitest 覆盖 auth/questionnaire/public-questionnaire 关键路径。

## 7. 典型使用流程

```
管理员登录 → 新建问卷（填文案/评分标准，批量传音频+模型名）
→ 设置组别 → 生成盲测配对 → 发布得到分享链接
→ 分发链接给评审人 → 评审人免登录逐对打分
→ 管理员查看 Analytics（GSB + Wilson + 显著性）→ 得出模型优劣结论
（可复制问卷用于下一轮评测）
```
